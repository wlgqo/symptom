# 症候群主动监测预警系统

传染病症候群主动监测预警系统，支持病例采集、症候群识别、风险分析、预警模型计算、病例管理与数据可视化展示。

## 技术栈

- **后端**: Java 8+ / Spring Boot 2.7 / Spring MVC / MyBatis / Thymeleaf
- **前端**: HTML5 / CSS3 / JavaScript / ECharts
- **数据库**: SQLite

## 功能模块

1. **发热呼吸道症候群监测预警** - 三间分布分析、临床特征、预警模型、预警处置
2. **发热伴出血症候群重症死亡监测** - 重症率/死亡率统计与病例详情
3. **发热伴腹泻症候群病例风险管理** - 高风险筛查与风险评级
4. **症候群主题库条件树搜索** - 可视化条件组合查询
5. **主动监测病例管理** - 多条件查询、修改、日志、报卡、导出
6. **系统管理** - 用户管理、模型配置、操作日志

## 快速启动

```bash
mkdir -p data
mvn clean package -DskipTests
java -jar target/symptom-monitor-1.0.0.jar
```

启动后访问 http://localhost:8080
